YOUR TYPE - Production environment setup
========================================

These variables must be added to the SERVER environment (Render/Vercel/your Node host).
Never put Shiprocket or Razorpay secrets inside admin.html or GitHub.

SITE_URL
  Your public website URL, for example https://your-type-shop.vercel.app

TEST_MODE
  false  = normal production behaviour (recommended)
  true   = optional local/testing mode only; it may generate a TEST AWB and is NOT a real courier shipment.

-------------------------
SHIPROCKET
-------------------------

SHIPROCKET_EMAIL
  Your Shiprocket account/API login email.

SHIPROCKET_PASSWORD
  Your Shiprocket account/API password.

SHIPROCKET_PICKUP_LOCATION
  Exact pickup/warehouse location name configured in Shiprocket.

SHIPROCKET_PICKUP_PIN
  6-digit pickup PIN configured for that Shiprocket pickup location.

Optional package defaults (Admin can override these while creating a shipment):
SHIPROCKET_DEFAULT_WEIGHT_KG = 0.5
SHIPROCKET_DEFAULT_LENGTH_CM = 20
SHIPROCKET_DEFAULT_BREADTH_CM = 15
SHIPROCKET_DEFAULT_HEIGHT_CM = 5

Shiprocket flow in this build:
  YOUR TYPE Admin -> Create Shipment -> Shiprocket order -> serviceability -> courier selection -> AWB assignment ->
  AWB/courier/shipment ID saved in YOUR TYPE -> Packing Slip + Track Order.

If Shiprocket credentials are missing, the Create Shipment action fails safely instead of generating a fake production AWB.

-------------------------
IMPORTANT
-------------------------

1. Do NOT send passwords/tokens in chat.
2. Add them only to the hosting provider's Environment Variables/Secrets.
3. After adding/changing variables, redeploy/restart the server.
4. Do not set TEST_MODE=true on a production store.
5. A real AWB is considered working only after Shiprocket returns it and YOUR TYPE saves it to the order.
